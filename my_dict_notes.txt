# Мои заметки по словарям
- keys() - возвращает ключи
- values() - возвращает значения
- items() - возвращает пары ключ-значение
- get() - безопасное получение значения
- update() - обновляет словарь
- pop() - удаляет ключ и возвращает значение
- setdefault() - вставляет ключ, если его нет
- fromkeys() - создает словарь из последовательности
